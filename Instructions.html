Instructions

Use this workspace to prepare event variables, plan adventures, and generate outputs such as tags and templates.

Event Variables Adventure Listing Loot Calculation NPC Listing

Recommended Workflow

  1. Start in Event Variables and enter event name, number and difficulty.
  2. Open Adventure Listing and import the listing as per Google Forms
  3. Use Generate Template on each adventure row to create the Word templates to send.
  4. Once Registration closes, complete remaining event varilables, perfrom Loot Calculation + Adventure DC
  5. Complete Loot allocations, tags and scheduling
  6. Export all data and templates for Event prep

Template generation on local files requires selecting the .docx template once using Select Word Template.

Tips

  • Most pages share data through localStorage, so update event details first.
  • If a page looks out of date, refresh and reopen it from the menu.
  • Keep exported files in the event folder for easier packaging and handoff.
